# Lian V. Garcia Portfolio

A responsive portfolio website tailored to Lian's resume for remote Quantity Surveyor, Construction Estimator, and Construction VA applications.

## Files
- `index.html` — complete responsive website
- `LIAN-GARCIA-CV.pdf` — add your resume PDF here
- `assets/` — recommended folder for project screenshots and portfolio samples

## Before publishing
1. Put the final resume PDF in this folder and name it `LIAN-GARCIA-CV.pdf`.
2. Replace the three project placeholder visual blocks with redacted screenshots/photos of actual work.
3. Add individual case-study pages or modal sections for takeoffs, BOQs, estimates, and supplier comparisons.
4. Only publish project information that you are permitted to share.
5. Verify all project dates and performance figures before publishing.


Project detail pages are intentionally simple photo galleries with short descriptions, not case studies. Replace gallery placeholders with shareable project photos.


All Projects page: every project now includes a “View My Work” link to a simple photo-gallery page with a short description.

## Project gallery layout
Each individual project page uses the same 5-photo gallery: one large photo on the left and four smaller photos in a 2×2 grid on the right. Replace each `<div class="scene"></div>` inside `.photo` with an `<img src="..." alt="...">`. Clicking a real image opens it full-screen; placeholders do nothing until an image is added.


## Non-disclosure naming
Project names are anonymized as Project 1 through Project 6 throughout the public-facing site and URLs.

## Confidentiality
Project names, sizes, durations, and other identifying details are anonymized in the public portfolio.
